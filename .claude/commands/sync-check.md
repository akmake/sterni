# Sync Check

Before modifying any file, read `docs/sync-map.md` and identify every file that must change in sync.

Steps:
1. Read `docs/sync-map.md`
2. Find the row matching the file(s) about to be changed
3. List all coupled files that must also be reviewed/updated
4. Confirm with the user if the scope is larger than expected before proceeding

If the file isn't in the sync map yet, note that it should be added after the task.
